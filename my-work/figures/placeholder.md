# Figures

This folder holds the figures produced by `../04_extension_blocked_vs_random_validation.ipynb`
(the "Figures for the README" cell near the end of the notebook).

| File | What it shows |
|---|---|
| `headline_validation_optimism.png` | **A:** mean √(burnt area) by year, 2011–2015, showing why raw losses cannot be compared across years. **B:** skill relative to climatology promised by validation vs achieved on the held-out year 2015, for random-split and year-blocked validation (3 seeds). |
| `qq_2015_excesses.png` | Pooled QQ plots of the 2015 test excesses on unit-exponential margins, for the GPD model chosen under each validation scheme (seed 1). |

To regenerate: run Notebook 04 in Google Colab, download both PNGs from the
`figures/` folder in Colab's file panel, and upload them here.
